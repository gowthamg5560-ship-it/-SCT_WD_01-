# 🌴 Areca Palm Products

A simple and responsive agriculture information website designed for Areca Palm farmers.

The website provides information about Areca Palm plants, fertilizers, pesticides, diseases, market prices, weather information, and useful farmer tools.

---

## 🌱 Project Overview

**Areca Palm Products** is a static web application developed using:

- HTML5
- CSS3
- JavaScript

The project does **not use any live API or backend server**.

All weather and market information displayed on the website is static/sample information.

▶️ How to Run
Method 1: Open Directly
Download or clone the project.
Open the project folder.
Double-click index.html.
The website will open in your browser.
No installation is required.
Method 2: Using VS Code
Open Visual Studio Code.
Select:
File → Open Folder
Select:
areca-palm-products
Open index.html.
Right-click the file.
Select Open with Live Server if the Live Server extension is installed.
🌐 GitHub Pages
This project can be hosted directly using GitHub Pages because it is a static website.
Upload to GitHub
Open Command Prompt or VS Code Terminal inside the project folder.
Run:
git init
Then:
git add .
Then:
git commit -m "Initial Areca Palm Products website"
Rename the branch:
git branch -M main
Add your GitHub repository:
git remote add origin https://github.com/YOUR-USERNAME/areca-palm-products.git
Push the project:
git push -u origin main
Replace:
YOUR-USERNAME
with your GitHub username.
🚀 GitHub Pages Setup
After uploading the project:
Open your GitHub repository.
Go to Settings.
Select Pages.
Under Build and deployment, select:
Source: Deploy from a branch
Branch: main
Folder: / (root)
Click Save.
GitHub will provide your website URL.
