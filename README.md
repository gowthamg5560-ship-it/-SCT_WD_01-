
# 🌴 Areca Palm Products

A simple and responsive agriculture information website designed for Areca Palm farmers.

The website provides information about Areca Palm plants, fertilizers, pesticides, diseases, market prices, weather information, and useful farmer tools.

---

## 🌱 Project Overview

**Areca Palm Products** is a static web application developed using:

- HTML5
- CSS3
- JavaScript

The project does **not use any live API or backend server**.

All weather and market information displayed on the website is static/sample information.

---

## ✨ Features

### 🏠 Home
- Attractive landing page
- Areca Palm agriculture theme
- Navigation to different sections

### 🌴 Plants
Information about:
- Areca Palm seedlings
- Young plants
- Hybrid plants
- Plant care

### 🌱 Fertilizers
Information about:
- Organic fertilizers
- NPK fertilizers
- Micronutrients
- Water-soluble fertilizers

### 🧪 Pesticides
Provides basic pesticide management information.

### 🦠 Diseases
Information about common Areca Palm problems such as:
- Leaf spot
- Root problems
- Bud rot
- Plant inspection

### 📊 Market
Displays sample/reference Areca Nut market prices for selected districts.

### 🌦️ Weather
Provides sample weather information for selected Karnataka districts.

Districts included:
- Chitradurga
- Shivamogga
- Davanagere
- Hassan
- Tumakuru
- Bengaluru
- Mysuru
- Chikkamagaluru
- Udupi
- Kodagu

### 🛠️ Farmer Tools
Includes:
- Planting Guide
- Irrigation Guide
- Crop Calendar
- Fertilizer Calculator information
- Disease Identification information
- Price Alert information
